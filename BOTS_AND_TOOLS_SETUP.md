# 🤖 Bot Configuration & Automation Guide
## Essential Islamic & Utility Bots for Khafos's Server

To make the server truly interactive, educational, and secure, add and configure these free, reliable Discord bots:

---

### 1. 🕋 QuranBot (The Core Islamic Companion)
* **What it does:** Allows members to look up any Quranic verse with audio recitations, Arabic text, and translations in 30+ languages.
* **Website:** [quranbot.org](https://quranbot.org) or search in Discord App Directory.
* **Top Commands for Members:**
  * `/quran ayah surah:2 ayah:255` — Displays Ayat al-Kursi with audio recitation.
  * `/quran tafsir surah:1 ayah:1` — Displays classical commentary.
  * `/quran search query:patience` — Searches all verses mentioning patience (Sabr).
* **Automated Daily Reminders:**
  * In `#daily-ayah-hadith`, configure QuranBot to send an automatic Ayah of the Day at Fajr time.

---

### 2. 🐢 Carl-bot (Reaction Roles, Moderation & Welcome)
* **Website:** [carl.gg](https://carl.gg)
* **Role Assignment:**
  * Use Carl-bot to bind reaction emojis to roles in `#verify-and-roles`:
    * React 📢 ➔ `@Khafos Announcements`
    * React 📖 ➔ `@Daily Ayah & Hadith`
    * React 🎙️ ➔ `@Live Halaqah & Stage`
* **Automod Words & Slurs:**
  * Add automatic deletion and warns for vulgarity, blasphemy, and NSFW phrases to keep the server pure.

---

### 3. 🎫 Ticket Tool (Private Inquiries & Islamic Questions)
* **Website:** [tickettool.xyz](https://tickettool.xyz)
* **Usage:**
  * In `#ask-knowledge-seekers`, create a button: `📩 Ask a Private Islamic Question`.
  * When a member clicks it, it opens a private channel visible only to the member, Khafos, and the `Talib al-'Ilm` staff. This allows members to ask personal Fiqh or spiritual questions in complete privacy and modesty.

---

### 4. 🛡️ Native Discord AutoMod (Built-in Security)
Enable these in **Server Settings ➔ AutoMod**:
1. **Block Mention Spam:** Limit mentions to maximum 3 per message.
2. **Block Suspected Spam Content:** Enable Discord's native spam filter.
3. **Custom Keyword Filter:** Add words like `nitro`, `gift`, `free discord`, profanities, and inappropriate terms with an automatic 1-hour timeout.

---
